        今天加班到10点，一直在犹豫我的测试要不要用模型的形式还是直接传递期望值。

传递期望值：

优点，简单直接。缺点，需要人工分析，可重用性差！

参考模型：

需要花费时间，麻烦，代码更复杂，可读性降低。

优点：可重用性强，减少分析时间。

如果用模型，怎么在单个test里直接应用：

我的想法是先定义好默认输入

clrn, clrnall, mask, maskall, en, flag, inverter

drive_flag(chn, flag)

if (flag = 1) value =1 else =0

if(mask) …

if (maskall)

输出:

stat, statall, notglob, notintx, noint

如果是非锁存型的

stat = flag

statall = stat

锁存型的

if (flag)

stat = 1

if (!clrn)

stat = 0

notglob = mask&amp;maskall&amp;stat

notint = (notglob&amp;en)^invert
