如何高效使用 Code Agent：以 PiCode 为例的实用指南

本文以 PiCode（一款 CLI 上的 Code Agent）为例，总结了一套与 AI 助手高效协作的方法论。无论你使用哪款 Code Agent，这些技巧都同样适用。 什么是 Code Agent？ Code Agent 不是一个普通的聊天机器人，它能够读取文件、执行命令、修改代码、调用 API，并在多个步骤之间保持上下文、自主决策。你可以把它理解为一个「会写代码的助理工程师」——你给方向，它负责落地。 PiCode 的能力边界大致如下： 能力 说明 读写文件 读取、创建、修改本地任意文件 执行命令 运行 shell 命令、测试、构建 调用 API GitHub、飞书、GitLab 等外部服务 记忆上下文 跨会话记住项目背景和你的偏好 多步规划 将复杂任务拆分为步骤并依次执行 沟通技巧：怎么说，AI 才能真正理解你 1. 说「做什么」，而不是「怎么做」 不好的提问方式： “帮我在第 42 行后面加一个 if 判断，检查 x 是否大于 0，如果是就 return” 好的提问方式： “函数 calculate() 在 x 为负数时会崩溃，帮我修复这个 bug” Code Agent 有能力自己决定最合适的实现方式，你只需要描述目标和问题，不需要手把手指挥每一步。 2. 提供足够的上下文 AI 不会读心术。如果你的需求有背景，请一起说出来： 1 2 3 4 5 6 # 弱上下文（AI 可能猜错方向） 帮我优化这个函数的性能 # 强上下文（AI 能精准执行） 这个函数每秒被调用 10 万次，当前耗时 2ms，目标是降到 0.5ms 以内， 主要瓶颈可能在字符串拼接这里，帮我优化 上下文的关键要素： ...
